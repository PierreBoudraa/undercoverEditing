Undercover Video Maker

A local Windows app that transcribes a short French Undercover clip, lets the creator review clue matches, and renders an MP4 with player words and timed clue overlays.

One active session stays in memory. faster-whisper and FFmpeg run locally; there is no account, database, or hosted service.

One render, end to end

  1. Choose Render Send the reviewed entries and marker positions. app.js · startRender()
  2. Validate and queue Check matches, collect the active session, track the job. main.py · start_render()
  3. Compose the video Write ASS overlays, render with FFmpeg, validate the MP4. rendering.py · render_annotated_video()
  4. Preview and download Serve the current output and allow transcript corrections. main.py · get_output()

The rendered file is local at workdir/final.mp4. It preserves the source dimensions; the transcript’s player assignments are supplied by the creator.

Reference route through the code

1. Browser action

In app/static/app.js, follow startRender() to see the request and job polling. showRenderedVideo() connects success to the player and download link.

2. Session and job

In app/main.py, start_render() validates review entries; _run_render() passes the data to the renderer and records whether the output is current.

3. Media output

In app/rendering.py, render_annotated_video() generates the ASS file, reports FFmpeg progress, checks the result, and publishes the final MP4.

To change this, start here

  • Overlay title, word sizing, role glows, and clue stacking: app/rendering.py, especially build_clue_events(), _text_dialogues(), and build_ass_content().
  • Render preconditions and output freshness: app/main.py, especially start_render() and _output_is_ready().
  • Overlay font, size, glow, stack spacing, and safe margins: app/config.py. The bundled Chewy font and Apache license are in assets/fonts/.
  • Transcription model and word timestamps: app/transcription.py, especially transcribe_words().
  • Render progress and what the browser displays: app/static/app.js, especially renderRenderJob() and showRenderedVideo().

A practice to reuse

Measure pipeline stages before optimizing. On this sample, transcription took about 78% of the first run, while alignment and ASS generation together took under a tenth of a second. If speed becomes a real problem, test transcription settings or model size and verify the four clue matches still work.

The timing hooks are in app/transcription.py, app/main.py, and app/rendering.py; progress/timing behavior is covered by tests/test_rendering.py.

Run it again on Windows

py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000

Open http://127.0.0.1:8000. The first transcription run downloads the faster-whisper model into the local cache. Rendering uses imageio-ffmpeg’s bundled binary; if its ASS subtitle filter is unavailable, follow the FFmpeg fallback in README.md.
